*************************************************************************************
Operand Types（操作数类型） 
reg: General-purpose register (寄存器; e.g., eax, ebx, rax, etc.)
addr: Memory address (地址; e.g., [esp], [ebx + 4], [0x12345678]), referring to the value stored at that address
val: Immediate value (立即数常量; e.g., 5, -10, 0xFF)
All operations assume 32-bit x86 mode. In 64-bit mode, stack operations should adjust the stack pointer by 8 bytes instead of 4.
-------------------------------------------------------------------------------------
1.Push the value onto the stack (to save it)
src:
    push reg/val/addr
des:
    sub esp,4/8
    mov esp,reg/val/addr
-------------------------------------------------------------------------------------
2.Pop a Value from the top of the stack and store it in 
src:
    pop reg/addr
des:
    mov reg/addr,esp
    add esp,4/8
-------------------------------------------------------------------------------------
3.Call the function address named
src:
    call label
des:
    push eip
    jmp funcaddr
-------------------------------------------------------------------------------------
4.return from the function address
src:
    ret [n]
des:
    pop eip
    [add esp,n]
-------------------------------------------------------------------------------------
5.Calculate an address and store the result in  register or address, without accessing memory.
src:
    lea reg/addr,addrExpr
des:
    mov reg/addr,addrExpr
remark: This is the simplest one; more complex examples have not been shown.
-------------------------------------------------------------------------------------
6.Increment or decrement the value of a register or address by 1.
src:
    inc / dec reg/addr
dse:
    add / sub reg/addr,1
-------------------------------------------------------------------------------------
7.Exchange the values of two operands.
src:
    xchg reg1/addr1,reg2/addr2
des:
    push reg1/addr1
    mov reg1/addr1,reg2/addr2
    pop reg2/addr2
-------------------------------------------------------------------------------------
8.Negate the value in a register or address, i.e., compute the two's complement additive inverse.
src:
    neg reg/addr
des:
    not reg/addr
    inc reg/addr
-------------------------------------------------------------------------------------

Push / Pop all 32 bit geneal Register
-------------------------------------------------------------------------------------
src:
    pushad
des:
    push eax
    push ecx
    push edx
    push ebx
    push esp
    push ebp
    push esi
    push edi
remark: This push stores the current value of the esp register — i.e., its original value before being modified by pushad.
-------------------------------------------------------------------------------------
src:
    popad
des:
    pop edi
    pop esi
    pop ebp
    add esp, 4    ; 跳过栈中保存的 ESP 值（不恢复它）
    pop ebx
    pop edx
    pop ecx
    pop eax
remark: popad does not restore ESP, which could cause the stack pointer to become inconsistent.
-------------------------------------------------------------------------------------

Key Definitions (核心定义说明)
N is the size of the function's local variables. (N 是函数局部变量的大小。)
M is the size of the function's arguments (or parameters). (M 是函数传入参数的大小。)
-------------------------------------------------------------------------------------
_stdcall (Standard Call) —— 内部平栈
(被调函数负责清理参数，通常用于 Windows API)
x86 Caller's Preparation (x86 调用前的准备)
Before jumping to the target function, the Caller performs these steps:
Push Arguments: Push the function arguments onto the stack (from right to left).
Execute call: Pushes the Return Address onto the stack and jumps to the function.
Standard Function Frame Overview (标准函数帧如下)

push ebp        ; Save the caller's base pointer (Old EBP)
mov ebp, esp    ; Set the current stack pointer as the new base pointer
sub esp, N      ; Allocate N bytes of space on the stack for local variables
……              ; Other Code (Function Body)
mov esp, ebp    ; Deallocate local variables by resetting the stack pointer
pop ebp         ; Restore the caller's base pointer (Old EBP)
ret M           ; Pop Return Address to EIP, AND clean up M bytes of arguments (Internal Stack Cleanup)
(注：标准写法通常用 ret M 代替 add esp, M + ret，M 为参数的总字节数)
-------------------------------------------------------------------------------------
_cdecl (C Declaration) —— 外部平栈
(调用者负责清理参数，C/C++ 默认约定，支持可变参数)
x86 Caller's Preparation (x86 调用前的准备)
Before jumping to the target function, the Caller performs these steps:
Push Arguments: Push the function arguments onto the stack (from right to left).
Execute call: Pushes the Return Address onto the stack and jumps to the function.
Standard Function Frame Overview (标准函数帧如下)

push ebp        ; Save the caller's base pointer (Old EBP)
mov ebp, esp    ; Set the current stack pointer as the new base pointer
sub esp, N      ; Allocate N bytes of space on the stack for local variables
……              ; Other Code (Function Body)
mov esp, ebp    ; Deallocate local variables by resetting the stack pointer
pop ebp         ; Restore the caller's base pointer (Old EBP)
ret             ; Pop Return Address to EIP, then jump back (NO argument cleanup here!)

x86 Caller's Cleanup (x86 调用后的清理 - 仅限 _cdecl)
After the function returns, the Caller must perform this step:

add esp, M      ; Clean up the arguments that were pushed onto the stack earlier (External Stack Cleanup)
-------------------------------------------------------------------------------------
