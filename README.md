# 逆向工程实战手册：从C++底层到Windows核心

> **项目简介**：这是我个人从零开始学习逆向工程的完整实战记录。本项目不仅包含系统化的学习笔记（Note），还配套了从C++底层内存、栈帧分析到PE文件解析的完整实战代码（Demo）。旨在通过“理论+实践”的双向驱动，揭开Windows程序运行的底层奥秘。

---

##  学习路线图

本项目按照**“底层原理 -> 核心机制 -> 实战演练”**的路线进行组织，带你一步步撕开高级语言的伪装，直面内存与汇编。

### 第一阶段：理论奠基 (Book & Notes)
在动手写代码之前，必须先建立正确的底层思维。
- ** 逆向工程入门（基础篇）**：由我亲自起草的入门教程。以“特工”为隐喻，系统讲解C++内存本质、汇编指令与栈帧机制，降低逆向入门的理解门槛。
- ** 核心知识笔记 (Note/)**：
    - `Symbol.txt`：C++ 符号修饰解码表，破解名称粉碎。
    - `AsmNote.txt`：x86 汇编指令与栈操作的底层逻辑。
    - `x86 Segment...txt`：段寄存器与保护模式详解。
    - `Memory Note.txt`：虚拟内存、分页机制与蓝屏原理。

###  第二阶段：实战演练 (DemoTest)
理论结合实践，通过亲手编写和调试代码，验证底层原理。

#### 1. 栈帧与函数调用 (`Stack Project`)
- **目标**：理解程序的“档案室”管理机制。
- **实战内容**：通过 `StackTest.cpp` 动态还原 x86 栈帧布局，验证 `EBP`、`ESP` 在函数调用中的变化，以及参数传递的真实过程。

#### 2. C++ 对象模型逆向 (`ClassAndObject Project`)
- **目标**：撕开 C++ 语法糖，直面内存布局。
- **实战内容**：
    - **内存穿透**：绕过 `private` 限制，直接修改对象成员。
    - **静态成员**：验证静态变量存储在全局区。
    - **手动内存管理**：模拟 `new/delete` 的底层实现。
    - **虚表劫持 (Hook)**：通过篡改 `vptr` 实现多态逻辑的动态替换。

#### 3. PE 文件格式与手动映射 (`PE Project` &  `Windows-PE`)
- **目标**：掌握 Windows 可执行文件的灵魂与 API 运用。
- **实战内容**：深度解析 DOS头、NT头、节表及导入/导出表和练习 Windows 核心 API 的调用；实现 PE 文件的手动内存映射（Manual Map）与修复，这是理解 DLL 注入与免杀技术的基础。

#### 4. 辅助验证与基础 (`float_test`)
- **目标**：夯实计算机基础。
- **实战内容**：验证 IEEE 754 浮点数存储标准。

#### 5. 并发编程基础 (`Thread Project`)
- **目标**：掌握多线程与线程池技术，为后续注入与Hook打下基础。
- **实战内容**：
    - **Win32 API 线程**：使用 `CreateThread` 与互斥体 (`Mutex`) 实现基础多线程同步。
    - **线程池 (Thread Pool)**：利用 Windows 线程池 API 实现高效的并发任务处理。
- **注**：这个和逆向工程关系是不大，后续学了新东西会补，但就是想放在这里。

##  如何使用本仓库

1. **阅读笔记**：建议先浏览 `reserve-book/、Note/` 文件夹下的文档，建立对内存、汇编和系统机制的初步认知。
2. **阅读教程**：参考《逆向工程入门（基础篇）》理解 C++ 底层的“特工”隐喻。
3. **调试代码**：
   - 使用 Visual Studio 打开对应的 `.cpp` 文件。
   - **强烈建议**：在 Debug 模式下配合“内存窗口”和“反汇编窗口”单步调试，亲眼观察内存数据的变化。
